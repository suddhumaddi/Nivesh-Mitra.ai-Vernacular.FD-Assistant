## 🚀 Overview

**Nivesh Mitra AI** is a multilingual financial assistant that helps everyday Indians understand and choose the best Fixed Deposit (FD) — in under 5 seconds.

Designed for **Tier 2 / Tier 3 users**, it simplifies complex banking terms into clear, actionable insights.

---

## 🎯 Problem

A user sees:

> “Suryoday Bank — 8.50% p.a. — 12M tenor”

…and has **no idea what to do.**

Financial products are:
- full of jargon ❌  
- hard to compare ❌  
- confusing for non-English users ❌  

---

## 💡 Solution

Nivesh Mitra AI:

- 🧠 Understands user input in **natural language**
- 🌍 Supports **English, Hindi, Telugu**
- ⚡ Gives **instant FD recommendations**
- 📊 Shows **clear comparisons across banks**
- 📘 Explains all FD terms in simple language
- 📄 Generates downloadable **investment summary PDF**

## 🧠 How It Works


User Input → Intent Engine → FD Calculator → Recommender → UI Renderer


### Core Components:
- `intent_engine.py` → extracts amount & duration  
- `fd_calculator.py` → computes returns  
- `recommender.py` → selects best bank  
- `chat_ui.py` → renders UI  
- `translations.py` → multilingual system  
- `pdf_generator.py` → report creation  

---

## 🛠️ Tech Stack

- **Frontend**: Streamlit  
- **Backend**: Python
